# ア系 1/5：「ʌ」

これは日本語の「ア」にたぶん一番近い音

ただ、はっきり「ア！」って発音するときの半分くらい口を開けて、
弱く「ァ」って発音する感じ

<span style="height: 2px; background-color: gray; display: block; margin: 20px 1;"></span>

「ʌ」
英単語 / 発音記号表記
* f<b>u</b>n / f<b>ʌ</b>n
* c<b>u</b>t / k<b>ʌ</b>t
* j<b>u</b>mp / dʒ<b>ʌ</b>mp

<strong>注意！
例をみると"u"はいつでも「ʌ」の発音にみえるけど、違う綴りもたくさんあります:thumbsup:</strong>

---

# ア系 2,3/5：「ɑ」「ɑː」

「ɑ」：思いっきり口の中を大きく開けて「ア」って発音する感じ
「ɑː」：「ɑ」を伸ばして発音してみよう、「ː」はのばし棒と思えばざっくり合ってます

どれくらい大きく開けるかって？
そうだなあ、卵を１個口の中に詰め込む感じで開けて、「ア」っていってみよう:egg:
「ア」と「オ」の間くらいの音になったらうまくできてる！

<span style="height: 2px; background-color: gray; display: block; margin: 20px 1;"></span>
<div class="flex fw">
<div style="--fw: 1;">

「ɑ」
* t<b>o</b>p / t<b>ɑ</b>p
* h<b>o</b>t / h<b>ɑ</b>t
* r<b>o</b>ck / r<b>ɑ</b>k
</div>

<div style="--fw: 4;">

「ɑː」
* f<b>a</b>ther / f<b>ɑː</b>ðər
* c<b>a</b>lm / k<b>ɑː</b>m
</div>
</div>

# ア系 4/5：「æ」

よく「ア」と「エ」の中間っていわれる音

意味わからないって？
はっきり「ア！」って言おうとする口を作って、「エ」と言ってみよう
もしくはめっちゃ高速、もはや同時に「エア」っていう感じでもオーケー！

<span style="height: 2px; background-color: gray; display: block; margin: 20px 1;"></span>

「æ」
* <b>a</b>pple / <b>æ</b>pl
* c<b>a</b>rrot / k<b>æ</b>rət
* c<b>a</b>tch / k<b>æ</b>tʃ

---

# ア系 5/5：「ə」

これは難しい、、けど大切！
ほんの少し口開けて、何の力も入れずにただ声を出してみよう
「ア」っぽく聞こえなくもないけど、「ア」と言おうとしているわけでもない感じ

アクセント(<b>ˈ</b>)がついていない「aiueo」が「ə」の音に変化する！
＊アクセント(<b>ˈ</b>)：単語の中でも強く長く読む部分のこと

<span style="height: 2px; background-color: gray; display: block; margin: 20px 1;"></span>

「ə」
* J<b>a</b>pan / dʒ<b>ə</b>ˈpæn
* par<b>e</b>nt / ˈper<b>ə</b>nt
* childr<b>e</b>n / ˈtʃɪldr<b>ə</b>n
* at / æt → What are you looking <b>a</b>t? / <b>ə</b>t

# オ系 1,2/2：「ɔ」「ɔː」

また、アメリカ英語では「ɔː」と「ɑː」もほとんど同じで発音されることがある

# R系：「ər」

「ər」：日本語では表せないんだこの音は、、

ごめんなさい説明頑張ります笑、伝わってくれ:pray:

1. まずは「ら」と言ってみよう
「ら」と言うとき、最初に舌の先端が口の中の天井に当たるよね？
1. 次は舌が口の天井に当たらないように「ら」と言ってみよう
1. もうほぼ完成してる！
あとは舌を口の天井に当てない「ら」から「あ」を取ったら「ər」っぽい音が完成

<span style="height: 2px; background-color: gray; display: block; margin: 20px 1;"></span>

「ər」
<div class="flex fw">
<div style="--fw: 1.;">

* s<b>er</b>ve / s<b>ər</b>v
</div>
<div style="--fw: 1.;">

* wat<b>er</b> / wɔːt<b>ər</b>
</div>
<div style="--fw: 1.;">

* c<b>ur</b>t / k<b>ər</b>t

# 二重母音：aɪ, eɪ, ɔɪ, aʊ, oʊ, ɪər, ʊər, eər

とってもシンプル、基本的には今まで覚えた音を組み合わせるだけ
- a:ア、ɪ:イ、ʊ:ウ、e:エ、o:オ、みたいな感じで発音（雑）
- 前半の音を長めに発音して
- そこから滑らかに後半の音につなげ
- 後半の音は短めでフィニッシュ！

<div class="flex fw">
<div style="--fw: 1.;">

## 発音記号の表記が違う！

<strong>注意！発音記号はいろいろな表記がある！</strong>
表記が違くても表現したい音は同じなので、惑わされないように

- ɔ = ɒ → cot / k<b>ɔ</b>t, k<b>ɒ</b>t
- ər = ɜːr, ɚ → serve / s<b>ər</b>v, s<b>ɜːr</b>v, s<b>ɚː</b>v
- ou = əu → boat / b<b>oʊ</b>t, b<b>əu</b>t
- ei = eɪ → day / d<b>eɪ</b>, d<b>ei</b>
- ɔi = ɔɪ → boy / b<b>ɔɪ</b>, b<b>ɔi</b>
- ɪər = iər, ir, ɪr → here / h<b>ɪər</b>, h<b>ɪr</b>, h<b>ir</b>
- ʊər = ʊr → tour / t<b>ʊər</b>, t<b>ʊr</b>
- eər = er → hair / h<b>eər</b>, h<b>er</b>
